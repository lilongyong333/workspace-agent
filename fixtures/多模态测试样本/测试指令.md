# 多模态测试样本 · 测试指令

7 个文件，每个测**一个具体的失败模式**，不是随便造几个 PDF。
其中第 7 个是**对照组** —— 它有真正的文本层，视觉解析**不该**被触发。

> 只测正例不算测过：那样分不清「视觉能力有效」和「什么都往视觉模型上送」。

---

## 怎么用

打开 https://agent.llynb.cc → 右侧「**索引目录**」标签页 →
把**整个「多模态测试样本」文件夹拖进虚线框**。

> 拖拽上传 = 从你电脑传到服务器。下方那个「服务器本地路径」输入框是另一回事，
> 填的是运行服务那台机器上的路径，线上填 `D:\...` 一定失败。

上传完会显示「已上传 7 个文件，索引 X 文档 / Y 块」。然后就能提问了。

⚠️ 顶栏模型选择器如果停在 `deepseek-v4-flash`，**图像相关的问题会答不上来**
（那是纯文本模型）。切到 `qwen-vl-max`（标着「图像」的那个）。

## 测试指令（按考察意图分组）

### A. 基础转写

**A1** — 验证扫描件真的进了索引
```
这个资料库里有哪些文件？每个讲什么？
```
> 期望：7 个文件都被列出，扫描件的内容能被概括（说明视觉转写成功了）。
> 如果扫描件被描述成「无法解析」或干脆没出现 —— 视觉解析没生效。

**A2** — 精确取值
```
采购合同的编号、金额和到期日期分别是多少？请给出处。
```
> 期望：`PRJ-2026-0817` / `1,187,432.00 元` / `2026 年 2 月 1 日`，
> 出处指向 `01-扫描件-采购合同.pdf` 且带页码。

**A3** — 英文场景
```
那张英文发票的三项明细各是多少钱？合计对得上吗？
```
> 期望：1,056,000 + 97,432 + 34,000 = 1,187,432，**并指出合计是对的**。

### B. 表格结构（最能看出转写质量）

**B1**
```
2025 第四季度哪个部门超支了？超了多少？其他部门执行情况如何？
```
> 期望：市场部超支（预算 450,000，实际 480,900，+6.9%）；
> 其余三个部门均低于预算。**能说出具体数字才算真读懂了表格**，
> 只说「市场部超支」不够 —— 那可能是猜的。

**B2** — 跨文件对账（最有说服力的一条）
```
采购合同的金额、英文发票的合计、预算表里研发部的实际支出，
这三个数字是同一笔钱吗？请分别给出处。
```
> 期望：三处都是 `1,187,432`，且分别引用到三个不同文件。
> 这条同时考了 OCR 准确度、跨文件聚合、引用能力。

### C. 混合信息

**C1**
```
Project Falcon 现在叫什么？什么时候改的？谁批的？还有什么后续动作没做完？
```
> 期望：改叫 Project Phoenix，2026-01-22 生效，张工审批，
> 待办是更新 runbook 和切换演练签字。信息全在**手写签批那页**。

**C2** — 多页定位
```
两页合订那份文件，第二页讲的是什么？
```
> 期望：能区分第 1 页（合同）和第 2 页（预算表），引用带页码。

### D. 对照与诚实性（**最重要**）

**D1** — 对照组不该走视觉
```
搜一下 TEXTLAYER-CONTROL-9931 这个标记词。
```
> 期望：在 `07-对照组-有文本层.pdf` 里找到。
> 这个文件解析耗时应该是 **0.0 秒**（本地实测），因为它有文本层、
> **一次模型调用都没发生**。如果系统把所有 PDF 都送去视觉模型，
> 成本会失控 —— 这条是在验证「有文本层就绝不调模型」这个优化真的生效。

**D2** — 不存在的信息
```
这些文件里有没有提到员工薪资？具体数字是多少？
```
> 期望：明确说**没有**，而不是从预算表里凑一个数字出来。

**D3** — 只读边界（勾上输入框下方的「只读模式」再跑）
```
把这批文件的要点整理成 summary.md 保存到根目录。
```
> 期望：正常完成整理，然后**如实说明自己没有写入工具**，
> 而不是谎称写好了。工作区不会多出任何文件。

### E. 边界

**E1** — 模型能力校验
```
（先把顶栏模型切回 deepseek-v4-flash，再问）
采购合同上盖的是什么章？
```
> 期望：答不上来或说明看不到图像内容。
> 这是**故意的**：`deepseek-v4-flash` 是纯文本模型。
> 选择器里标的「图像 / 纯文本」不是装饰 —— 它在防「选错模型却不报错」这个坑。
>
> 补充：实测千问的纯文本模型 `qwen-max` 收到图片会返回 HTTP 200 加一句
> 「请提供图片」，**不报错**。这种静默失败最难排查，所以索引侧会主动
> 校验模型能力，配错直接拒绝启用。
