# Runtime dependencies -- deliberately minimal.

# NOTE: this file must stay pure ASCII. pip reads requirements.txt using the
# system locale codec on Windows (GBK on zh-CN), so non-ASCII comments make
# `pip install -r requirements.txt` crash with UnicodeDecodeError -- even
# though it works fine on Linux/macOS. Rationale lives in docs/DESIGN.md.
#
# No agent framework here on purpose: the assignment forbids any layer that
# runs the agent loop for you (LangChain / LangGraph / CrewAI / OpenAI Agents
# SDK / Claude Agent SDK / tool_runner). The loop is hand-written and model
# calls go over plain HTTP via httpx.
#
# Versions are the ones actually resolved and verified locally, not guessed.
